# UK Clinical Dietetics Intelligence

A dashboard for UK dietitians: NDNS and ONS surveillance, NHS/NICE/SACN guidance, research and point-of-care tools (MUST, refeeding risk).

- `index.html` — the dashboard (navy design, live Europe PMC / GOV.UK / Google Books searches).
- `data.json` — figures, evidence feed and reference texts. A weekly Claude routine updates this file from official sources (ONS, NHS England, OHID, NDNS, NICE, SACN, FSA, DHSC) and commits it here.

Clinical tools and summaries support, not replace, professional judgement and local policy.
